# Fiverr gigs (paste-ready)

Three gigs, all text or spreadsheet work I (Claude) do; Rudra only uploads the file and sends the delivery message. No calls, no camera.

Rules baked in (Fiverr ToS): no links, emails or phone numbers anywhere in the gig or chats; never send a buyer to Gumroad or the calculator site; all payment stays on Fiverr; AI use is disclosed in the FAQ (Fiverr requires disclosure when asked, we do it up front so no buyer can say they were misled).

Field limits used: title ≤80 chars, no & / + " characters; 5 tags ≤20 chars; description ≤1,200 chars (checked by script, see bottom). Gig images are in `gig-images/`.
