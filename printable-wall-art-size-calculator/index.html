How print size, pixels and DPI fit together

A printer lays down a fixed number of pixels per inch. Divide your image's pixels by that number and you get the largest print that stays sharp.

Largest print (inches) = pixels ÷ DPI

Pixels needed = print size (inches) × DPI

300 DPI is the standard for prints people look at up close. 200 DPI usually looks fine on a wall, and big posters viewed from across a room get away with 150. Most buyers of printables print at home or at a print shop and expect 300.

Worked example: why AI art often fails as wall art

A typical AI image is 1024 × 1536 pixels, a 2:3 portrait. At 300 DPI that prints at only 3.4 × 5.1 inches, smaller than a 4x6 photo. It prints none of the 24 standard sizes in the table sharply. Selling it as a 24x36 poster means the buyer gets a blurry print and you get a refund request or a bad review.

To cover every 2:3 size up to 24x36 at 300 DPI, the master file needs 7,200 × 10,800 pixels. Upscale first, check the detail at 100% zoom, then export.

A buyer prints a smaller size from the same file because the ratio is the same, so you don't need one file per size. Big 300 DPI files can pass 20MB as PNG; a high-quality JPG of the same image is usually far smaller. If you want to offer more than five files, a ZIP counts as one file but must also stay under 20MB.

Print on demand works the same way

Printify, Printful and Gelato all list a pixel size per product. A poster or canvas has the same math as a printable: inches × DPI. Shirts and mugs have their own print areas, so check the product's template, but the rule holds: if the file has fewer pixels than the print area needs, the print comes out soft.

Questions

What size should printable wall art be for Etsy?

Design at 300 DPI in a few master ratios rather than one file per size. A 2:3 file of 7,200 × 10,800 pixels covers 4x6 up to 24x36; add 3:4, 4:5, 11x14 and ISO files to cover the other common frames.

How many pixels do I need for an 8x10 print?

2,400 × 3,000 pixels at 300 DPI, or 1,600 × 2,000 at 200 DPI.

How many pixels for a 24x36 poster?

7,200 × 10,800 at 300 DPI. At 150 DPI, which works for a poster seen from a distance, it is 3,600 × 5,400.

Is 300 DPI the same as 300 PPI?

For digital files, sellers use the terms the same way: how many image pixels land on each printed inch. The DPI number saved in a file's settings changes nothing on its own; only the pixel count matters.

How many files can I upload to an Etsy digital listing?

Up to 5 files, each up to 20MB. A ZIP counts as one file.
